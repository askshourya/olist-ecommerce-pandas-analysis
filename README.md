# 🛒 Brazilian E-Commerce Data Analysis

## 📌 Project Overview

This project analyzes the Brazilian E-Commerce (Olist) dataset using Python and Pandas.

The goal was to explore e-commerce orders, customers, products, payments, delivery performance, and customer satisfaction through a real-world business case study.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Jupyter Notebook

## 📊 Analysis Performed

### Order Analysis

* Order status analysis
* Missing-value analysis
* Duplicate analysis
* Year/month/day analysis
* Delivery date analysis

### Customer Analysis

* Customer distribution by state and city
* Unique customers
* Repeat customers
* Repeat customer percentage

### Product & Sales Analysis

* Total revenue
* Freight costs
* Product/category analysis
* Quantity sold
* Revenue by category
* Average product price

### Payment Analysis

* Payment method distribution
* Payment installments
* Payment type vs review score

### Customer Satisfaction

* Review-score analysis
* Review score by order status
* Review score by payment type
* Product category vs review score

### Delivery Analysis

* Delivery time calculation
* Delivery-time groups
* Delivery time vs review score

## 📁 Dataset

Dataset: Brazilian E-Commerce Public Dataset by Olist

Source:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The original CSV files are not included in this repository.
